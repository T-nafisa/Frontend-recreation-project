# Soupy Frontend Website

This is a simple one page website's frontend recreation, of a soap shop, landing page called **Soupy**. The project was built during my CS355 course taking under professor Nikola Baci using only **HTML, CSS, and JavaScript**.

## Features

* Clean landing page layout
* Hero section with navigation, social icons, cart icon, headline, button, and product image
* Product section with three soap items
* Quantity selector for each product
* JavaScript functionality for increasing and decreasing item quantity
* Responsive layout for smaller screens

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```text
icons/
images/
index.html
styles.css
script.js
README.md
```

## JavaScript Functionality

The `+` and `-` buttons update the quantity number for each soap item. The quantity cannot go below `1`.
